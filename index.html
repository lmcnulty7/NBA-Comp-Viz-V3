From broadcast pixels to possession value, measured against ground truth at every step.

A tool for reviewing basketball possessions, built on player tracking data. It opens with a question. Can a TV broadcast stand in for the tracking data that teams buy?

You are looking at a still frame. The video clips sit on a private copy of this site. Ask for access to watch them.

  1. This is an NBA game the way you see it on TV. A single camera, always moving.

  2. Teams buy tracking data that says where every player stands, many times a second. This demo measures how close the TV picture alone can get.

  3. There is an answer key. The league's own tracking system, SportVU, recorded this same game. This page calls that the sensor data.

  4. These models learn from example footage. That is called training. The models that find the court and the players never trained on this game. A filter that runs first did. It picks out the wide camera shots, and some of its training frames came from this game.

  1. A box on a screen is not a spot on the floor. The camera pans and zooms, so the same pixel is a new place in every frame.

  2. A second model finds the painted court lines in each frame. The lines show where the camera is pointing.

  3. Then the spot where each player stands can be placed on a flat map of the court, measured in feet.

  4. This step has no score of its own. The sensor data tracks players, not painted lines. So the map is judged by where it puts the players. That is next.

Each value here is a point estimate.

  1. Positions only matter if the answers built on them hold up.

  2. This is an illustration, not a test. The same models ran twice on 25 stretches of this game. Once on sensor positions. Once on broadcast positions. The models were locked before this run. Each one was built again from the same code and the same training games. It was used only if it gave back its saved answers. Nothing was changed to fit the broadcast.

  3. Shot quality is the chance that a shot goes in. It moved by 3.2 percentage points on average. That is across 43 shots.

  4. Possession value is the points a possession is worth at each moment. It moved by 0.026 points on average. That is across 942 moments.

  5. Then the average defender. The spot where one would stand moved by 3.304 feet on average. That is across 71 cases.

  6. The broadcast tracker misses players, so the missing ones were filled in from the sensor data. That is 48.7 percent of all player positions. Boxes that matched no player were dropped. Names, teams and the ball come from the sensor data too. So these numbers show what position error alone does.

  7. Can the broadcast stand in yet? No. It misses players and it has no ball. That is why the model results on this site come from sensor data or from play-by-play records, not from the broadcast.
