Caveats

  • testable frames are the B4 set: frames where the V3 H matched >= 6 players; every build is scored on them until ROADMAP R1.3 widens the truth, so the set leans toward frames V3 already handled
  • the truth H is fitted through V3's own boxes (0.33 ft median residual on the feet) and is valid only near those feet: drawn over the frame it sits about as far from the painted court as V3's H (reports/sportvu_truth_line_check.txt, found 2026-10-04), so the court line row is not measurable and missed-player and ghost-box counts, which project through H_truth away from the fitted players, carry that error; position error and near-field bias compare only matched players near the feet
  • gsw_phx_2016: local windowed rebuild of the harvest sections (25 windows of running clock scored), not the production artifacts
  • gsw_phx_2016: wide reference = gate v2 at its v2 threshold; gate v2 was trained on human-verified harvest frames including this game (in-sample here, so closer to the human label than a held-out gate); live = running clock read by OCR at 1 s resolution
  • referee class = models/player_detector.pt's own referee class at the player confidence; its referee recall has never been measured against human labels, and a box with IoU >= 0.5 to a referee detection can be a player standing beside the referee (see referee_boxes_within_ghost_ft_of_a_player)
  • id switches are counted between consecutive testable frames (sparse samples), so a switch and switch-back between samples is missed: a lower bound
  • team accuracy uses the best A/B to team mapping per window, an upper bound on what a fixed mapping would score
  • cle_nyk_2015: local windowed rebuild of the harvest sections (16 windows of running clock scored), not the production artifacts
  • cle_nyk_2015: wide reference = gate v2 at its v2 threshold; gate v2 was trained on harvest frames including another CLE home game (gsw_cle_xmas16), not this one (reports/sportvu_splits.txt); live = running clock read by OCR at 1 s resolution
  • cle_gsw_2016: wide reference = gate v2 at its v2 threshold; gate v2 was trained on harvest frames including another CLE home game (gsw_cle_xmas16), not this one (reports/sportvu_splits.txt); live = running clock read by OCR at 1 s resolution
  • cle_gsw_2016: local windowed rebuild of the harvest sections (30 windows of running clock scored), not the production artifacts
  • Build r23 is the best of the three training seeds of its recipe on the held-out arena, so the recipe's expected error on a new arena is larger than this build's arena rows (ROADMAP_LOG.md, third scaling pass; PLAN.md D52).

Method

  • match ft: 5.0
  • identity match ft: 2.5
  • miss ft: 2.5
  • ghost ft: 3.0
  • line target px: 3.0
  • referee iou: 0.5
  • referee conf: 0.4
  • shot reset s: 1.0
  • min possession frames: 5
  • wide threshold v2: 0.33
  • paired n gsw phx 2016: 24 windows, 11292 observations
  • paired n cle nyk 2015: 14 windows, 3862 observations
  • paired n cle gsw 2016: 12 windows, 1178 observations
  • paired: r23_replay minus r23_cam on the observations both builds score (95% CI, window bootstrap); the metrics are errors, so a positive difference means r23_cam is better

Notes

  • Intervals are 95 percent percentile intervals of a bootstrap by game unless a section says otherwise; a value with no interval is a point estimate.
  • Question, model name and verdict are the cells of the hand-written Summary table of reports/results.md, copied word for word with only the Markdown bold markers removed: the verdict is a quote from the write-up. The out-of-fold and held-out metrics and the rows are copied from the tables that analytics/results.py generates from each lane report.
  • The verdict class comes from the generated tables where they decide it. A lane scored by a correlation with a stated out-of-fold interval that contains zero is failed; with no out-of-fold interval and a held-out interval that contains zero it is inconclusive. Any other lane is no_signal when its selected model is no better out of fold than a floor candidate of its own table (a constant, a mean, a prior, a uniform or majority reference, persistence), and works when it beats every such floor. The build stops if this class and the class the write-up's sentence names disagree. No class is a default.
  • Lanes whose table decides no class (no correlation interval and no floor candidate), classed by the word of the write-up's own sentence instead: xfg, embeddings.
  • Lanes classed by their table alone, because the write-up's sentence names no class: gravity.
  • Held-out games were scored once, by the models frozen at the tag named in freeze_tag.
