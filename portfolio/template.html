In brief

What this is, and what it is not

I built a system that watches ordinary NBA television broadcasts and writes down, for each possession, which team had the ball, who was on the floor, and what the possession produced — the kind of positional record the league's own arena camera arrays generate, recovered instead from footage anyone can watch. It runs as a chain of eight stages, each doing one job: deciding whether a frame shows live play at all, finding the players, mapping the picture onto the real court in feet, following bodies through occlusion, telling the two teams apart, cutting the game into possessions, pairing defenders with attackers, and reading the scorebug clock so every span can be matched to the official play-by-play.

Broadcast video is hostile to all of this. The camera pans and zooms continuously, so the relationship between pixels and the floor changes every frame. The director cuts to replays, close-ups and crowd. Players occlude one another in uniforms designed to be identical. There is no identity channel, no ball track, and no clock except the one drawn into the picture. A pipeline can be assembled to cope with each of these — the components are mostly standard — and it will produce numbers whether or not it is working. That is the problem this page is organised around.

Two things distinguish this page from the usual demo. Every stage carries its own held-out or human-labeled number, reported next to the limitation that number does not cover. And the whole chain is scored against something it never sees: the official play-by-play, which records the same possessions from an entirely separate source. Where the checks caught my own errors — a headline corrected downward, a labeled dataset mostly discarded after a hand audit, a teacher model rejected on measured evidence — those are shown as exhibits, not footnotes, because a system whose failures are invisible is not a system whose failures are absent.

What follows walks the chain in order — the gate, then finding and placing players, then one real possession followed end to end, then the one stage that has no number, then the end-to-end result as an interval — before turning to what the instrument caught, what this project refuses to claim, and what a reviewer can verify. The measurements support a narrow claim: on the possessions that survived every stage, against their opponents' own norms, with an interval that currently straddles zero. There are no player ratings here and no league-wide conclusions; the matchup stage is unmeasured and the page says so at the same weight as the wins.

01 · 2026-09-12A 300-label hand audit found the LLM judge's labels {{N:label_audit.judge_adjudicated_bands.range_pct_str}} right; discarded before any model trained on them.

The log said

6,159 of 6,197 stratified frames judged by Claude Haiku through the Batches API for $10.80 (41 failures, 0.7%): labels ready to train on.

What was true

Rule 4 of the label protocol — a human audits 300 stratified accepted labels before anything trains — found the unjudged agreement band at {{N:label_audit.agreement_band.accuracy|pct}}% [{{N:label_audit.agreement_band.wilson95.0|pct}}, {{N:label_audit.agreement_band.wilson95.1|pct}}] (n = {{N:label_audit.agreement_band.n_judged}}) and every judge-adjudicated band at {{N:label_audit.judge_adjudicated_bands.range_pct_str}} (n = {{N:label_audit.judge_adjudicated_bands.n_total}}). Errors were not near-misses.

What changed

Kept the 37,916-box agreement corpus (teacher and pipeline agreed, no judge involved); discarded every judge-adjudicated band and the 4,694 jersey-number reads riding on it — before any retrain consumed them. Recorded design defect (CLAIMS A6): the qualification gate could only fire on classes with an in-house comparator, and the exempted classes are exactly the ones that failed — absence of a comparator had been read as permission.

Why this is judgment: the cheap signal (a judge's verdicts) looked like data until a human sample said otherwise; the sample was pre-committed, so the answer could not be argued with.

02 · 2026-07-18A 197-minute Grounding DINO pass missed more real players than the in-house detector; the retrain never happened.

The log said

Grounding DINO, after a 197-minute GPU pass over 6,197 frames, was ready to label.

What was true

On identical human-labeled frames it scored P 0.70 / R 0.94 vs the in-house detector's P 0.956 / R 0.967 — 27 vs 15 false negatives; even while over-proposing, it missed more real players.

What changed

The retrain never happened; four artifact explanations (coordinate normalization, index misalignment, draw-before-downscale, crowded numbering) were ruled out before accepting the result.

These P/R figures come from a different matcher than the F1 {{N:detection.f1_str}} headline in Find / follow / place; do not cross-compare.

Why this is judgment: a bigger model with a longer log is not a better teacher; the comparison was run on the same frames before a single label was accepted. ⌗ DEVLOG 2026-07-18

03 · 2026-06-24Every epoch "completed" on Apple MPS; the keypoint head had learned nothing (mAP 0).

The log said

Every epoch of the court-keypoint model completed on Apple MPS; box metrics improved.

What was true

Keypoint loss flat at ~11.4 and keypoint mAP exactly 0 — the head that mattered learned nothing; a CPU run dropped it 11.5 → 7.7 in 11 epochs. Two stacked root causes: an MPS gradient bug, and degenerate box targets from collinear keypoints.

What changed

That model trains on CPU; rule born — verify artifacts by content, never by log line. Every clip on this page was verified the same way (frame count by ffprobe, a mid-frame extracted and looked at).

Why this is judgment: "completed" and "learned" are different claims; the second needs an artifact. ⌗ DEVLOG 2026-06-24

04 · 2026-07-16A content-hash guard refused a stale join on its first deployment.

The log said

Fresh timestamps on the possession join (00:10) and the credit table built from it (00:11), and the table looked plausible.

What was true

The join was stamped the previous morning — it had crashed on Colab, the wrapper never checked exit codes, and credit aggregated stale data.

What changed

The join records a content hash of every outcomes file it consumed; credit hard-exits on mismatch (content, not mtime). On the very next run a zip that accreted old files tripped it — the guard refused a real stale join on first deployment. A failed alignment now skips join and credit entirely.

Why this is judgment: a plausible table is the most dangerous output a pipeline can produce; the fix checks content, not timestamps. ⌗ DEVLOG 2026-07-16

05 · 2026-07-07macOS silently kept the old mp4s; the "fixed" renders had never been written.

The log said

Ghost-free videos re-rendered.

What was true

macOS AVFoundation silently refuses to overwrite an mp4 — the "fixed" renders were the old files.

What changed

Unlink first, assert the writer opened, then pixel-scan every fresh mp4 and count banner frames against the JSON exclusion counts (104 / 43 / 50 / 60 matched). The same ritual produced every clip on this page.

Why this is judgment: the writer returned success; the file on disk was the test. ⌗ DEVLOG 2026-07-07

06 · 2026-07-121080p moved jersey OCR 30.8% → 31.0%; the extra pixels bought longer tracks instead.

The log said

Jersey-number OCR is limited by 720p.

What was true

A controlled 1080p A/B moved read rate 30.8% → 31.0% — saturation; the extra pixels bought ~3× longer tracks and team-call abstention 53% → 11% instead.

What changed

Effort moved to targeted crops and multi-read aggregation; a fragment named "#34 GSW" on visibly purple crops was actually the opposing #34 — a number legal on both rosters — which spawned a crop-color veto.

Why this is judgment: the obvious lever was measured before it was pulled, and the measurement redirected the work. ⌗ DEVLOG 2026-07-12
