NBA CV: Privacy policy

Last updated: November 25, 2026.

NBA CV is a personal research tool for the project at lmcnulty7.github.io/NBA-Comp-Viz-V3. Its owner is its only user. It is not offered to the public.

What it accesses

When its owner signs in with Google, the tool asks for three permissions:

  • Google Colab, to start and run computing jobs in the owner's own Colab account.
  • Read-only access to Google Drive, to read project files the owner placed there.
  • Access to Drive files the tool creates, to save job results back to the owner's Drive.

What it does with the data

The tool moves the owner's project files between the owner's own Drive and the owner's own Colab jobs. It does not sell, share or send this data to anyone else. It does not use the data for advertising. It does not collect data about anyone else.

Where sign-in keys are kept

Sign-in keys stay on the owner's own computer, readable only by the owner. Short-lived keys (about one hour) are passed to the owner's own Colab jobs.

How to remove access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions go through the project's GitHub page: github.com/lmcnulty7/NBA-Comp-Viz-V3.
