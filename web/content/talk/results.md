# The models, as tested

Each model was tested once on games it never saw. The verdicts come from the write-up, word for word.

## Notes

- Read the held-out value and its interval from each row. A value with no interval says it is a point estimate.
- Failed and inconclusive models stay in the table. Decisions and matchups are shown as tested with no signal.
- The full table, with the report of each model, is on the results page.
